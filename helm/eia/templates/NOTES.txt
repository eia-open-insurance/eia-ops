The Ingress expects host "{{ .Values.ingress.host }}". Point it at the ingress controller:
  kind:     add "127.0.0.1 {{ .Values.ingress.host }}" to your hosts file (with the kind port mapping)
  minikube: add "$(minikube ip) {{ .Values.ingress.host }}" to your hosts file

Without an ingress controller, port-forward the entry points:
  kubectl -n {{ .Values.namespace }} port-forward svc/eia-shell 3000:{{ .Values.shell.port }}
  kubectl -n {{ .Values.namespace }} port-forward svc/eia-gateway 8080:{{ (.Values.platform.gateway).port }}
The shell nginx proxies {{ .Values.ingress.remotesPrefix }}/<vertical>/ to the web Services, so the
shell forward also serves the federated UI. Optional FS-RI simulator forward:
  kubectl -n {{ .Values.namespace }} port-forward svc/eia-fsri-simulator 8181:{{ .Values.simulators.fsri.port }}
{{- end }}

Health endpoints use Spring Boot Actuator at /actuator/health on each service port.
This chart is a local single-node deployment. It is not the production gate evidence (SPEC 17.10).
